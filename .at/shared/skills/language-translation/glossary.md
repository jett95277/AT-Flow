# AT Language Glossary

Use these Chinese display terms when translating AT platform text. Keep core
technical nouns (`agent`, `artifact`, `provider`, `prompt`, `pipeline`,
`session`) in English and use the Chinese term in parentheses on first mention
when helpful.

| English | 中文显示 |
| --- | --- |
| handoff | 交接 |
| outbox | 输出箱 |
| inbox | 输入箱 |
| workspace | 工作区 |
| context | 上下文 |
| contract | 契约 |
| permissions | 权限 |
| audit | 审计 |
| trace | 追踪 |
| state machine | 状态机 |
| retry | 重试 |
| acceptance criteria | 验收标准 |
| constraints | 约束 |
| non-goals | 非目标 |
| boundaries | 边界 |
| mission | 职责 |
| success criteria | 成功标准 |
| clarifying questions | 澄清问题 |
| scope | 范围 |
| priority | 优先级 |
| failure | 失败 |
| recovery | 恢复 |
| evidence | 证据 |
| verification | 验证 |
