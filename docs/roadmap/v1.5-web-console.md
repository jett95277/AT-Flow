# V1.5 Web Console

## Status

Completed.

## Mission

V1.5 adds a local Web Console for AT Flow while keeping the existing AT runtime as the single source of truth.

The Web Console is not a separate product path. It is a browser-based control surface over the same session, state machine, artifacts, trace, audit, and provider adapter contracts used by the CLI.

## Owns

- FastAPI backend around the AT runtime.
- React Web Console frontend.
- Local development ports:
  - frontend: `3000`
  - backend: `8000`
- Session list and selected session state.
- Workspace/document tree.
- Read-only document viewer.
- State machine visualization.
- Trace, audit, artifact, and error display.
- Runtime controls for creating sessions, running one step, continuing, retrying, and checking workspace health.
- SQLite console metadata for Web requests and local UI support.

## Architecture

```text
Browser
  -> React Web Console
  -> FastAPI Backend
  -> AT Runtime
  -> Provider Adapter
```

The backend is a controlled adapter. It should not expose arbitrary shell execution, arbitrary file reads, destructive file actions, or secret management.

## Verification Gate

V1.5 is complete only when:

- backend API health check works locally;
- frontend can load the runtime console;
- session list and state can be read from the backend;
- file tree and document viewer reject absolute paths and path traversal;
- a mock session can be created and advanced through the Web Console;
- trace, audit, artifact, and failure evidence are visible;
- backend tests, frontend tests, and frontend build pass.

## Does Not Own

- Production deployment.
- Public authentication system.
- WebSocket or SSE streaming.
- Browser-based file editing.
- File deletion, upload, or bulk filesystem operations.
- API key management UI.
- Multi-user or multi-tenant access control.

## Known Limits

- V1.5 is a local engineering console.
- Polling is used instead of realtime streaming.
- SQLite stores console metadata only; runtime state remains in `.at/`.
- The frontend is intended for local demonstration and debugging, not public unauthenticated access.
